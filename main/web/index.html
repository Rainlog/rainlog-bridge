Manual update

Install a Rainlog Bridge app .bin you trust, built for this board. Keep power connected during installation. The current firmware stays bootable if upload or validation fails.

Wi-Fi devices

Devices on the bridge's Wi-Fi. Open visits a device's own page (your weather station's settings live there).

Weather Underground

Optional. Relay each gauge to a Weather Underground station. The console keeps sending its Rainlog credentials; the bridge maps the Rainlog station ID to these WU credentials.
